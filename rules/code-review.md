# Code Review Prerequisites

When performing any code review — including via `/review` or PR review — you MUST invoke the `/coding-guidelines` skill first before starting the review.

## Review Submission

- When feedback requires changes, submit the review as **REQUEST_CHANGES** (not just a comment).
- All comments MUST be applied as inline review comments on the relevant lines of code, per file — not as top-level PR comments.
